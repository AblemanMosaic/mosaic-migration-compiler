# Security, evidence and process limits

The trust assumptions remain a cooperative local filesystem, accepted host code/interpreter,
actual cryptographic backend, and explicitly chosen policy/keys/clocks and target-to-store
mapping. No sandbox against arbitrary Python, a malicious administrator, kernel or evidence
producer is established. An internally consistent journal is not external publisher authentication.

A deterministic scheduler controls visibility and ordering, not truth. Withheld revocation cannot
be detected without delivery or a required freshness deadline. Equal-sequence contradictions are
kept; superseded positives cannot revive after a newer observation expires. Source coverage is
recognized testimony over a declared roster. The fixture has no hidden production services.

Primary simulation effects mutate rows through the real local T3 adapter. No cloud API, real
credential store, infrastructure namespace or production token is modified. The existing T4
regression suite includes explicitly scoped loopback HTTP tests. No external service is contacted
by this turn's migration simulations. Deterministic test scalars are intentionally public.

Loss of acknowledgment is UNKNOWN, not no effect. Reconciliation checks the accepted store ledger
before retries. Partial multi-target completion remains RECOVERY_REQUIRED; no automatic general
repair is invented. Compensation requires new exact approvals and preserves floors/revocations.
Restoring both databases and their external floor can restore stale knowledge; external floor
custody and physical power-loss durability remain unqualified.

Native P/PPI and UCM remain NOT_BOUND. Local scripts, model maps and passing product tests do not
establish construction-process host mediation. No retrospective admission or forced update occurs.
Actual Windows/WSL/macOS runs and independent review remain external gates. The tests do not measure
migration-design-error prevalence, operator-hours, AI token savings or comparative productivity.

Signing dependencies used here must be the declared genuine cryptography 46.x implementation;
absence refuses rather than substitutes a mock. Installed probes distinguish standard-library core
from optional signed operations. Copied installed distributions are not fresh dependency-resolution
evidence. No production publication/review submission is authorized by a passing local gate.
