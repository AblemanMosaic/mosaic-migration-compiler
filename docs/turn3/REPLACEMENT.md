# Replacing the T3 realization

Preserve the original program, foundation and T2 contracts separately. Pin the T3-O1 contract,
protocol, schemas and conformance corpus. The selected reader chooses the accepted evaluator
identity; a different implementation renews its realization binding and execution evidence.

A replacement must preserve canonical byte types/domains, statement/key/signature admission,
recognition scopes, high-water/freshness order, multi-jurisdiction denial precedence, model obligation
recomputation, and honest uncertainty. It must additionally qualify its own storage and target
adapter under explicit crash/CAS/idempotency assumptions. Passing pure court vectors does not prove
storage equivalence. Never regenerate expected outcomes simply to fit a port.

The read-only ABI is the pure conformance surface. Stateful Python APIs have separate replay and
fault tests. Known-answer outputs are authored-status/reference-assisted records, not independent
proofs. The traceability checker validates hashes, source symbols and actual named test execution;
it does not prove whole-program refinement or confer operational acceptance.
