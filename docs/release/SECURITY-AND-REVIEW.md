# Security and review dispatch

Subject: the exact Capability Layer T6 source, wheel, evidence envelope and program pin. Same-author engineering
qualification is not independent review. No external review submission or publication occurs here.

## Prioritized reviewer checks

1. Verify closed source/delivery inventories, test identities and source admission BEFORE test imports.
   Distinguish external pins from a self-consistent unsigned manifest. Check schemas/types, duplicate
   fields, path aliases, extra files, omitted cases and mismatched evidence contexts.
2. Trace the twelve primitives to compiler guards, T2 predicates and scoped T3 claims. Check unknown,
   false, stale, superseded and conflicting inputs; negative evidence cannot disappear in composition.
3. Review signature domains, key recognition, joint jurisdictions, scopes, interval/clock uncertainty,
   observation floors and no fallback to older positives after newer evidence expires.
4. Check prepare/approve/commit boundaries, intent-before-effect, concurrent requests, target identity,
   duplicate IDs, lost acknowledgment and honest partial effect reporting. Replay must not reissue.
5. Review work-order input minimization, submission/admission separation, stale-head refusal, fixed SDK
   selection, collectors, GUI context clearing and create-only exports. Data is not a code grant.
6. Run paired unsafe and safe retirement cases; scrutinize dormant/resumable work and persisted-state
   reader coverage. Foundry completion is bounded simulated evidence, not production safety.
7. Audit T6 release and study gates: missing platform/native/independent evidence must remain missing.
   Study protocol checks do not establish participant independence or honest measurement.

The host interpreter, OS, SQLite, cryptographic implementation, recognized keys, time, protected
floor and source coverage are trust dependencies. Arbitrary Python in the host is trusted code.
A worker cancellation discards its result; it is not a sandbox. Local writes assume cooperative
filesystems, not hostile admins/network filesystems/physical power-loss proofs. Payloads/exports
are neither encrypted nor secret-scrubbed. Public demo keys are unsuitable for real authority.

Keep all findings artifact-bound. Amend semantics explicitly; retain prior witnesses. Do not
rewrite frozen requirements/oracles or interpret green simulation tests as public-release approval.
