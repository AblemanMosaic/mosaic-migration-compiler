# Current integration boundaries

UCM operates beside MMC in shadow/conformance mode. `MMC_NATIVE` retains semantic authority;
`MMC_NATIVE_CONTROLLER` remains the effect executor. UCM validates and compiles the exact AMCAS
contract but does not replace MMC decisions, select an executor, grant a capability, or infer an effect.
Identity and jurisdiction are explicitly `UNBOUND`.

The Stage-I1 path executes four structural correspondence cases through the MMC-native
and UCM contract paths: exact T6 predecessor subject custody, retained control planes, pinned dependencies, and
the reconciliation effect inventory. Reconciliation is declared `WRITE_WORKSPACE` because it appends
an `OUTCOME` to the local controller journal. The resulting five-event UCM `CampaignJournal` is
hash-chained and verified before archival. Only the native controller observes the lost-ack outcome;
UCM validates the declared journal-write effect class. The comparison does not attribute the native
observation to UCM. Matching normalized results remain structural shadow correspondence,
not a proof that UCM and MMC are semantically identical.

CMBA a7 is pinned as an exact wheel and is used only for agent-protocol and artifact/result-binding
evidence. The current probe asks the exact wheel to construct and inspect an MMC-specific binding for
subject root, semantic authority, and effect executor; all three commitments must match. No command
installs it automatically. The a4 reader remains available only through the
historical T4 compatibility surface so predecessor replay does not silently change meaning.

SemCrys is optional compatibility transport for archive/custody experiments. The current checkout's
capability and native-runtime surfaces are probeable, but complete self-verification is held because
the Ultra asset is absent. MMC never treats a SemCrys container, legend, or compression result as
migration eligibility, evidence truth, source coverage, authorization, or proof of effect.

The dependency graph classifies UCM and CMBA as native current dependencies and SemCrys as optional
compatibility. Unknown or changed commits, trees, wheel bytes, dirty source checkouts, contract roots,
or control-plane roots refuse the current conformance probe. The current successor source is bound
separately in qualification and in the Stage-I1 session report; the immutable contract subject remains
the T6 compatibility baseline.
