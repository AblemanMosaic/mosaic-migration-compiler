# T2-D1 security and assurance boundaries

All observations, authorities, issuer keys and approvals in T2 inputs are SUPPLIED declarations.
The evaluators are deterministic predicates over those declarations. They do not verify signatures,
recognize a real observer, discover all writers, prove coverage, fetch revocations, attest clocks or
mediate production effects. T3 will bind and evaluate evidence under reader-selected authority.

A report root detects alteration relative to an accepted expected root. It does not authenticate
its producer. Recomputing verifies the specified finite relationship, not the truth of the inputs.
The same-author test corpus is not an independent cryptographic review or whole-program proof.

Separate compile/model-plan/model-retirement statuses deliberately retain NOT_EVALUATED eligibility.
Even all-positive declarations preserve the foundation's runtime guards. Never replace them with a
permission flag. A modeled simultaneous phase has no real atomicity absent a separately qualified
adapter. Do not implement such a phase as sequential writes and retain the atomic safety claim.

Retirement inventories derive from cohort members, roles and legacy flows in the supplied model.
That rejects omission relative to the model, not omission FROM the model. An unknown producer outside
the inventory can still invalidate real-world safety. The external model-acceptance and observation
coverage courts remain necessary. Positive fixture results cannot satisfy those gates.

Bounds cover canonical bytes/depth/nodes, domain arrays and planner search states. These are not an
OS memory sandbox or wall-clock deadline. The compiler reads installed trusted contract/code bytes;
callers run ordinary host code. Input data never imports a handler. No adversarial network, user
infrastructure, production credential, external court or published service is accessed here.

Key lifecycle checks are semantic consistency of modeled issuance/rotation/revocation intervals,
not proof a cryptographic key ceremony occurred. Storage counts and labels do not establish real
replication, residency or independence. Policy migration covers exact finite rules only. There is
no universal policy-equivalence solver or arbitrary schema-transform engine.

Native P/PPI remains NOT_BOUND. Local test admission/receipts are not a native workflow host. Missing
production, platform, research and independent-review legs retain their separate dispositions.
