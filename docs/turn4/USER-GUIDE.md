# Native migration workbench

Launch `mmc-workbench` in a graphical environment with Tk. Operational fixture evaluation additionally
needs cryptography 46.x. The interface is an obligation-first reader; it is not a production signing,
release deployment or autonomous agent console.

1. Open a bounded local workspace JSON or select the explicitly public demonstration. Import clears
   current assessment and selected reader; it does not load a trust store or adopt document pins.
2. Load a reader configuration deliberately, or enable the clearly marked PUBLIC FIXTURE CONTEXT
   checkbox for the demonstration only.
3. Assess. The underlying T3 courts recompute; inspect individual predicates, unknowns and quarantine
   rather than treating the headline as permission.
4. Select an unresolved claim and prepare a bounded work order. Load a signed response for review.
   Review is non-effectful; journal admission is a separate host API operation, not a GUI approval.
5. Inspect receipt history; imported rows are IMPORTED_NOT_REPLAYED until the selected current reader
   context can reproduce them exactly. Different time/evidence may legitimately require a new receipt.
6. Export a workspace or work order only by selecting a destination and confirming the exact bytes,
   filename, directory and digest. Existing targets refuse; no overwrite fallback exists.

## Ten views
Obligations shows blockers and exact decisions. Migration graph shows the admitted finite model and
planner order, not all live infrastructure. Inventory lists model objects. Reader policy exposes the
chosen policy and pins. Evidence lists supplied claims and their interpretation. Timeline and effect
history display a separately replayed supplied T3 journal. Courts retains predicate-level outcomes.
Replay & compare distinguishes imported from recomputed results. Agent & SDK shows bounded work,
submission review and fixed installed extension descriptors.

A journal import additionally requires a host-selected expected policy root and optional external
checkpoint. Recomputed projection does not establish the original host's custody. No journal replay
invokes a target effect. Source records are always rendered as text, never interpreted as instructions.

The one background worker is bounded in count. Cancellation invalidates/discards its result; it does
not terminate arbitrary Python/native code. No new worker begins until the old one exits. State changes
invalidate an old result before it can become current. Keyboard: Ctrl+O open, Ctrl+R assess, Esc cancel.

Workspace exports may contain sensitive source/evidence. They are unencrypted and not secret-scrubbed.
The GUI's confirmation is a local host control, not proof of informed human consent or organizational
approval. Demonstrations/tests simulate clicking confirmation in temporary directories.
