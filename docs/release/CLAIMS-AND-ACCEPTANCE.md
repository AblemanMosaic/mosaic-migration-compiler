# Claims and acceptance reconciliation

The original 84 requirements and 100 acceptance cases are unchanged. Capability Layer T6 must not erase
external prerequisites to report a completed local construction sequence.

The intended final ledger is 98 PASS_SCOPED cases, AC-REPRO-05 PARTIAL_PLATFORM_COVERAGE,
and AC-REPRO-06 BLOCKED_NATIVE_DEPENDENCY, conditional on all current mandatory local evidence.
AC-REPRO-08 is a scoped reconciliation pass: it requires accurate dispositions and a closed
review packet, NOT public release or independent approval. The program as a whole is NOT fully
qualified. Only platforms with actually supplied, identity-bound execution evidence may be listed.

The existing 78 model bindings remain. Six T6 requirements get delivery/reference mappings, but
mapping a requirement is NOT fulfilling it: R04/R05 require an actual independent study. W11-R04
also remains partial because native P/PPI/UCM integration is missing. No successor traceability
number changes those dispositions.

## Never infer these from green local tests

- Global discovery completeness, truth of recognized signed testimony or real-world residency.
- Production authority, live token issuance/data transfer, distributed atomicity/exactly-once.
- Physical power-loss durability or hostile-host custody.
- Native P/PPI mediation or an independent security review.
- Native Windows/WSL/macOS support from a py3-none-any wheel tag.
- Reduced engineer-hours, agent calls or economic break-even from one-author tests.

Records are unsigned same-author engineering evidence. External acceptance and an owner-selected
public license/release decision are still required. A metadata declaration is not a replacement
for its referenced evidence; release tools must validate the underlying files before aggregating.
